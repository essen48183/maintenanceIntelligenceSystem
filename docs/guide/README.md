| Doc | For |

layout, schema, API, and developer workflow. This `guide/` folder is the
human-readable counterpart.

> **Note on the `docs/` parent folder:** `docs/library/` is reserved for
> uploaded FAA / manufacturer PDFs (referenced from the `documents` table).
> Don't put end-user guidance there.
